Lesson 3. Database Design

Normalization is the process of organizing data in a database to reduce redundancy. A primary key is a column that uniquely identifies each row in a table. A foreign key is a column that links a row to a primary key in another table. Unlike a primary key, a foreign key can contain duplicate values.

Normal Forms
First Normal Form – removes repeating groups so that each cell holds a single value
Second Normal Form – removes partial dependencies on a composite key
Third Normal Form – removes transitive dependencies between non-key columns

Indexes are used to speed up searches in large tables. Views are used to show only selected columns to certain users. Poor normalization leads to update anomalies. When the number of duplicate records increases, the storage cost increases.

Steps in Designing a Database
Identify the entities
Define the attributes
Assign the primary keys
Define the relationships
Normalize the tables

Lesson 7. Nutrition and Health

A nutrient is a substance in food that the body needs to grow and stay healthy. Carbohydrates are used to give the body energy. Proteins are used to build and repair body tissues. Vitamins are used to help the body fight infections. The main food groups are grains, vegetables, fruits, dairy and protein foods.

Too much sugar leads to tooth decay. Lack of iron causes anemia. When physical activity increases, the body's need for energy increases. Water is more important than soft drinks for keeping the body hydrated. For example, brown rice is a whole grain.

Lesson 5. Internet of Things Integration

The Internet of Things (IoT) is a network of physical devices that collect and exchange data. A sensor is a device that measures a physical quantity such as temperature or humidity. An actuator is a device that performs an action such as turning on a pump.

Common IoT Protocols
MQTT – sends small messages through a broker using publish/subscribe
CoAP – transfers data between constrained devices using a request/response model
HTTP – exchanges data with web servers and cloud services

A gateway is used to connect local IoT devices to the cloud. Edge computing is used to process data near the devices to reduce delay. Weak passwords lead to device hijacking. When the number of connected devices increases, the network traffic increases. MQTT is lighter than HTTP for sending sensor readings.
